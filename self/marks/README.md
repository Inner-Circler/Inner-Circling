# self/marks/

Empty delegate for packaging/exceptions.toml's self/ entry — see
packaging/scaffold/self/README.md. MARK — the mechanism that wrote one
`<circle_id>.toml` file per circle close, the operator's own ratification
of that circle — was RETIRED WHOLESALE 2026-08-14 (docs/BNF.md), code
included. Nothing writes to self/marks/ any more; this delegate still
ships the empty directory so an old install's own leftover records are
not disturbed, not because anything new is expected to land in it.
